Dense

Single-line 24px rows laid out as columns: result number, type, title, URL and age. A column header sits under the input and a status line runs along the bottom with the mode, your position, counts by type, and the selected row's full URL. Ten results take about two-thirds the height of the stock bar.

Live preview. Type to filter, arrow keys or Tab to move.

Set it up on Chrome

Vimium C on Chrome only loads a custom Vomnibar page that lives inside an extension, so Dense comes as a tiny unpacked extension.

1

Download the repo

Get https://github.com/SeJoMaCode/vomnibar-dense (Code, then Download ZIP) and unzip it somewhere permanent. The extension folder is what you'll load.

2

Copy Vimium C's script into it

Open chrome-extension://hfjbmagddngcpeloejdejnfgbamkjaeg/front/vomnibar.js, press Ctrl+S, and save it as extension/front/vomnibar.js. This keeps it matched to your installed Vimium C, so redo it after Vimium C updates.

3

Load the extension

In chrome://extensions, turn on Developer mode, click Load unpacked, and pick the extension folder. Note the ID shown for Dense Vomnibar for Vimium C.

4

Point Vimium C at it

In Vimium C's options, under Advanced, set Preferred Vomnibar page to chrome-extension://<Dense ID>/front/vomnibar.html. In the Vomnibar settings box, set "sizes" to the value below, and add time to "styles" (for example "mono-url time") so the age column has data. Then reload your tabs.

5

Expect the stock bar now and then

On browser pages, the New Tab page and in incognito windows, Vimium C may still use its built-in Vomnibar.
